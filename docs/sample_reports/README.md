# Sample reports

Reports generated by the Deep Research Agent pipeline (with the **v0** fine-tuned
verifier), one per DRA-Bench question type, to illustrate the pipeline's output —
grounded narrative + per-claim verdicts/confidence + on-demand multi-format
(table / Mermaid diagram).

| file | question type |
|---|---|
| `mamba-state-space-models_deep-NLP.md` | deep NLP / AI (answer confidently) |
| `data-localization-laws_pros-and-cons.md` | pros-and-cons (both sides) |
| `alcohol-and-cardiovascular-health_contested.md` | contested (flag disagreement) |
| `best-programming-language_no-answer.md` | no-answer / ambiguous (report insufficient) |
| `cloud-providers-aws-azure-gcp_multi-format.md` | multi-format output (table + diagram) |

Mermaid diagrams render automatically on GitHub; in VS Code install
`bierner.markdown-mermaid` to preview them.
